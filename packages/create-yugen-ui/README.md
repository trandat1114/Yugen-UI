# create-yugen-ui

Create a [Yugen UI](https://trandat1114.github.io/Yugen-UI/) app from a template.

```bash
npm create yugen-ui@latest
npx create-yugen-ui@latest my-app --template saas
pnpm create yugen-ui my-app --template blog
```

Templates: `starter`, `saas`, `blog`, `dashboard`, `ai-chat` — previews at
[#/templates](https://trandat1114.github.io/Yugen-UI/#/templates).

This is a thin wrapper around [`yugen create`](https://github.com/trandat1114/Yugen-UI/tree/main/packages/cli#readme);
all of its options work here (`--pm`, `--no-install`, `--no-git`, `--force`, `-y`).

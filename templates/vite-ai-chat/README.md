# Yugen UI · AI chat

Starter template của [Yugen UI](https://trandat1114.github.io/Yugen-UI/#/templates) — Vite + React + Tailwind CSS v4.

```bash
npx create-yugen-ui@latest my-app --template ai-chat
cd my-app
npm run dev
```

Không muốn cài gì? Mở thẳng trên StackBlitz: https://stackblitz.com/github/trandat1114/Yugen-UI/tree/main/templates/vite-ai-chat

Kiểm tra cấu hình bất cứ lúc nào: `npx @yugen-ui/cli doctor` (xem https://trandat1114.github.io/Yugen-UI/#/concepts/cli).

File trong `src/blocks/` sinh từ `src/docs/block-library` bằng `scripts/sync-templates.mjs` — sửa thoải mái trong dự án của bạn.

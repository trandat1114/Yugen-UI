# Yugen UI · Dashboard

Starter template của [Yugen UI](https://trandat1114.github.io/Yugen-UI/#/templates) — Vite + React + Tailwind CSS v4.

```bash
npm create yugen-ui@latest my-app -- --template dashboard
cd my-app
npm run dev
```

Không dùng CLI: `npx giget@latest gh:trandat1114/Yugen-UI/templates/vite-dashboard my-app --install`. Không muốn cài gì? Mở thẳng
trên StackBlitz: https://stackblitz.com/github/trandat1114/Yugen-UI/tree/main/templates/vite-dashboard

Kiểm tra cấu hình bất cứ lúc nào: `npx yugen doctor` (CLI yugen, https://trandat1114.github.io/Yugen-UI/#/concepts/cli).

File trong `src/blocks/` sinh từ `src/docs/block-library` bằng `scripts/sync-templates.mjs` — sửa thoải mái trong dự án của bạn.

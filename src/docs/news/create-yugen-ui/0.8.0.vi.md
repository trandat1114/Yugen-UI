# Đi cùng @yugen-ui/cli 0.8.0

Cùng thay đổi với `@yugen-ui/cli` 0.8.0: template dùng `yugen-ui` 0.16 và chỉ kèm CSS của các component được import.

## Mới

- Ứng dụng mới dùng `yugen css`: CSS sau gzip từ khoảng 26 kB còn 12–20 kB. Template Vite chạy plugin `@yugen-ui/cli/vite`, template Next.js chạy watcher cùng `next dev`, nên import mới có style ngay khi dev. [→](/concepts/cli#css)

## Cải tiến

- `npm create yugen-ui` cài 2 gói thay vì 9: `@yugen-ui/cli` không còn dependency khi chạy. [→](/concepts/cli)
- `npx create-yugen-ui@latest my-app` tạo ứng dụng với template của 0.8.0, đặt `<Toaster />` rõ ràng trong `YugenProvider`. [→](/templates)

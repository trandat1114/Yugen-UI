# Theo @yugen-ui/cli 0.4.0

Cùng các thay đổi của `@yugen-ui/cli` 0.4.0: template Dashboard và AI chat đầy đủ, mọi template có tiếng Anh và tiếng Việt.

## Mới

- `npx create-yugen-ui@latest` có template Dashboard và AI chat đầy đủ; `--lang en|vi` dùng được cho mọi template. [→](/templates)

## Cải tiến

- `--lang` ghi đúng ngôn ngữ vào `index.html` (tiêu đề, description, Open Graph) và chuỗi có sẵn của component. [→](/concepts/cli)

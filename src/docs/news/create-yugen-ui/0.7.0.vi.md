# Đi cùng @yugen-ui/cli 0.7.0

Cùng thay đổi với `@yugen-ui/cli` 0.7.0: template dùng `yugen-ui` 0.15 có trang lỗi, React 19 và TypeScript 7.

## Thay đổi lớn

- Ứng dụng mới cần React 19 trở lên, như `yugen-ui` 0.15.0. [→](/concepts/cli)

## Mới

- Ứng dụng mới bắt lỗi render bằng `ErrorBoundary` và hiện trang trạng thái thay vì màn hình trắng. [→](/components/statuspage)

## Cải tiến

- `npx create-yugen-ui@latest my-app` tạo ứng dụng với template của 0.7.0. [→](/templates)

# In step with @yugen-ui/cli 0.8.0

The same changes as `@yugen-ui/cli` 0.8.0: templates on `yugen-ui` 0.16 that ship only the CSS of the components they import.

## New

- New apps use `yugen css`: the gzipped CSS goes from about 26 kB to 12–20 kB. Vite templates run the `@yugen-ui/cli/vite` plugin and the Next.js template runs the watcher beside `next dev`, so a new import is styled during dev. [→](/concepts/cli#css)

## Improved

- `npm create yugen-ui` installs 2 packages instead of 9: `@yugen-ui/cli` has no runtime dependencies. [→](/concepts/cli)
- `npx create-yugen-ui@latest my-app` creates apps with the 0.8.0 templates, which render an explicit `<Toaster />` inside `YugenProvider`. [→](/templates)

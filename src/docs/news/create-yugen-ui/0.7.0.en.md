# In step with @yugen-ui/cli 0.7.0

The same changes as `@yugen-ui/cli` 0.7.0: templates on `yugen-ui` 0.15 with error pages, React 19 and TypeScript 7.

## Breaking

- New apps need React 19 or later, like `yugen-ui` 0.15.0. [→](/concepts/cli)

## New

- New apps catch render errors with `ErrorBoundary` and show a status page instead of a blank screen. [→](/components/statuspage)

## Improved

- `npx create-yugen-ui@latest my-app` creates apps with the 0.7.0 templates. [→](/templates)

# Yugen Labs, gói npm & cộng đồng

Nhóm component vượt ra ngoài Fluent 2 — Trace, Questionnaire, Message Scroller, Code Block, Chart, Sheet thích ứng — cùng tầng Wait UX, bản build npm và trang cộng đồng.

## Mới

- Trace — minh bạch từng bước của agent AI, CI hay quá trình triển khai. [→](/components/trace)
- Questionnaire — khảo sát nhiều bước kiểu một-câu-một-màn-hình. [→](/components/questionnaire)
- Message Scroller, Message Bubble, Typing Indicator và Chat Composer cho giao diện hội thoại. [→](/components/messagescroller)
- Code Block có highlight, số dòng, diff, tab nhiều file và tab trình quản lý gói. [→](/components/codeblock)
- Chart (Bar, Line, Area, Donut, Sparkline, StatTile) theo quy trình trực quan hoá có kiểm định màu. [→](/components/barchart)
- Sheet — side panel trên desktop, bottom sheet kéo được trên mobile. [→](/components/sheet)
- Wait UX: Button loading, `useSpinDelay`, PageProgress, AsyncContent, ErrorState và Skeleton dựng sẵn. [→](/concepts/wait-ux)
- Gói npm `yugen-ui` với `theme.css` (Tailwind v4), `styles.css` (không cần Tailwind) và type declarations. [→](/concepts/quick-start)
- Trang Cộng đồng và trang Có gì mới. [→](/community)

## Cải tiến

- Carousel có loop, autoplay kèm tiến độ, peek và thumbnail; Accordion thêm kiểu separated / outline. [→](/components/carousel)
- Resizable có panel thu gọn được và lưu bố cục. [→](/components/resizable)

## Sửa lỗi

- Toàn bộ class Tailwind ở dạng canonical (script `lint:classes`) — không còn cảnh báo `suggestCanonicalClasses`.

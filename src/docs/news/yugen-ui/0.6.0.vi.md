# DataGrid, bộ AI, registry shadcn & kiểm thử tự động

Thêm DataGrid, bộ component AI (StreamingMarkdown, Citation, Reasoning, PromptInput), Tour, NotificationCenter, FileUpload, Stepper, TimePicker, Overflow và biểu đồ Scatter / Heatmap; cài từng component bằng shadcn CLI; docs nạp nhanh hơn, có tiếng Anh và hơn 800 bài test tự động.

## Mới

- DataGrid — sắp xếp, chọn dòng, đổi cỡ cột, ảo hoá 10 000 dòng. [→](/components/datagrid)
- Bộ AI: StreamingMarkdown an toàn, Citation, Reasoning, PromptInput có đính kèm. [→](/components/streamingmarkdown)
- Tour hướng dẫn có spotlight và NotificationCenter (popover / bottom sheet). [→](/components/tour)
- FileUpload, Stepper / Wizard và mẫu form react-hook-form + zod. [→](/components/fileupload)
- TimePicker, preset cho DateRangePicker và Overflow tự ẩn bớt item. [→](/components/timepicker)
- ScatterChart, Heatmap, AreaChart 100% và zoom / brush. [→](/components/scatterchart)
- Cài component dạng mã nguồn bằng shadcn CLI: `npx shadcn add …/r/<tên>.json`. [→](/concepts/shadcn-registry)
- Theme Designer xuất JSON (W3C Design Tokens, Tokens Studio). [→](/theme-designer)

## Cải tiến

- Docs nạp lười từng trang (JS lần đầu 970 kB → 108 kB), có bản tiếng Anh và menu chọn phiên bản. [→](/)
- Nút StackBlitz cho mọi ví dụ và chính sách phiên bản / deprecate. [→](/concepts/versioning)

## Sửa lỗi

- Sửa a11y (axe trên 128 trang × sáng / tối), Resizable kéo ngược trong RTL, lệch hydration khi SSR, tương thích React 19.

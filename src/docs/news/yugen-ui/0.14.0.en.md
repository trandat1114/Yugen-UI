# AppShell, Sortable and a Contributors page

AppShell builds the frame of an app: a sidebar that collapses to icons or opens as a Drawer on narrow screens, a top bar, the main content, a side column and a footer. The SaaS, Dashboard, AI chat, Admin, Docs, Store, Blog, Landing and Starter templates use it. Sortable reorders lists by drag and drop or with the keyboard: DataGrid column order, TagPicker tags and the Kanban board in the Admin template. The Contributors page credits the people who have helped Yugen UI (merged PRs, bug reports, suggestions and reviews), pulled from GitHub each time the docs are deployed. Each release also names its contributors on this page and in the CHANGELOG. The CSS can include only the components an app uses: on the templates it goes from about 25 kB to 14–19 kB gzip.

## Breaking

- Components' built-in text is English by default (the close button, "Loading…", chart descriptions, screen reader announcements), and `locale` defaults to `"en-US"` (dates, times, numbers, a 12-hour TimePicker). Vietnamese apps add `messages={messagesVi} locale="vi-VN"` to YugenProvider; source copied with the CLI uses the `…MessagesVi` sets. [→](/concepts/localization)

## New

- AppShell and Sidebar: the sidebar collapses to icons (item names show in a Tooltip) or hides completely, opens as a Drawer when the frame is narrow, resizes by dragging and toggles with Ctrl+B / ⌘B. Its state is saved in a cookie that the server can read when rendering. `layout="header"` runs the top bar across the full width, `scroll="page"` scrolls the whole page for content sites, and AppShellFooter adds a footer. [→](/components/appshell)
- Sortable: reorder lists with a mouse, touch, a pen or the keyboard (Space to pick up, arrow keys to move, Esc to cancel). Every step is announced to screen readers, and when dragging isn't possible, click a handle to pick an item up, then click where it should go. Vertical, horizontal and grid lists; SortableGroup for Kanban boards; the list scrolls on its own when you drag near an edge. No new dependency. [→](/components/sortable)
- Shared hooks: `useControllableState`, `useDisclosure`, `useMediaQuery`, `useLocalStorage` (synced across tabs), `useClipboard`, `useHotkeys` (skips text fields; arrow keys follow the text direction in RTL), `useDebouncedValue`, `useIntersection` and `useElementSize`. The components use these same hooks, so an app doesn't need a second hook library. [→](/components/hooks)
- Markdown: renders content written in Markdown (articles, release notes, CMS fields) with Prose typography. No HTML, and a `javascript:` link keeps only its label; relative links are kept, and `renderLink` hands links to the app's router. `inline` is for one-line text such as list items or table cells. [→](/components/markdown)
- CSS for the components you use: `yugen-ui/theme-core.css` is the theme without the scan of every component; add one `@import "yugen-ui/sources/<Component>.css"` line per component the app uses (each file also covers the components it uses inside). `yugen-ui/sources/index.json` maps every export to its file. `theme.css` stays the zero-config default. [→](/concepts/styling#lean-css)
- Contributors page: each person is a blossom on a cherry branch, opening in the order of their first contribution. Two sections: code and docs (merged pull requests), and ideas and discussion (ideas, bug reports, reviews, feedback in issues). Each person shows contribution counts by type and their recent contributions. [→](/contributors)

## Improved

- The docs open in English: `/components/button` is English and the Vietnamese version is at `/vi/components/button`. Your language choice is remembered, old `/en/…` links go to the new address, and browsers set to Vietnamese get a one-time suggestion to switch. [→](/)
- Component demos, the code you copy from them and the blocks are in English, with sample data in US dollars and en-US formats. Templates open in English too (Vietnamese with `create --lang vi`). Demos about Vietnamese input keep their Vietnamese text. [→](/blocks)
- The SaaS, Dashboard, AI chat, Admin, Docs, Store, Blog, Landing and Starter templates are built on AppShell: less repeated code, a collapsible sidebar, Ctrl+B and a skip link. [→](/templates)
- NavItem gains `tooltip`: the label shows when the sidebar is collapsed to icons. [→](/components/nav)
- DataGrid gains `columnOrder`; in DataGridColumnPicker, drag a column (or press Alt + ↑ ↓) to change the column order. TagPicker gains `reorderable` for reordering tags by dragging. [→](/components/datagrid)
- Each release names its contributors on the What's new page and in the CHANGELOG.
- Docs on phones: the props and Messages tables no longer scroll sideways (one block per prop or key, with labelled Vietnamese and English values), text in backticks renders as code, and opening an example's code widens its tile to the full row. Every component page fits a 375px screen.
- The What's new page is in English for every release of all three packages. Release notes are now written in Markdown, one file per release and language.

## Fixed

- CodeTabs and PackageManagerTabs: `className` applies to the outer box, so `w-full` in a flex row fits a narrow screen and the tabs wrap instead of running past it. [→](/components/codeblock)
- Copy buttons (CodeBlock, PackageManagerTabs…) report an error when the browser refuses the clipboard write, instead of still showing "Copied".
- Boot loading screen (Yugen Labs): the kanji numerals in the Enso and Bloom concepts are no longer cut off at the bottom in full-screen view. [→](/concepts/loading-screen)

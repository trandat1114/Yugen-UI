# Glass, six new templates and a column picker for DataGrid

A glass material (Yugen Labs) for toolbars, tab bars, sidebars and menus that float above content. Six new templates: Glass, Landing, Admin, Docs, Store and a Next.js starter; SaaS uses real paths, and every single-page app template comes with deploy configuration. People can hide and show DataGrid columns themselves. Long menus no longer run off the screen; on touch screens, buttons that used to appear only on hover are now always visible.

## New

- Glass (Yugen Labs, inspired by Liquid Glass): `material="glass" | "glass-clear"` on Toolbar, TabsList, Nav, MenuPopover, PopoverSurface, TooltipContent, DialogSurface, DrawerSurface and SheetContent; `appearance="glass" | "glass-prominent"` on Button; `appearance="glass"` on Input / SearchBox. TabsList gains `minimized` and the `useScrollMinimize` hook for tab bars that shrink while scrolling. Utilities: `glass`, `glass-clear`, `glass-tinted`, `glass-scrim`, `scroll-edge`, `rounded-concentric`. Text keeps 4.5:1 or more over any backdrop; glass turns opaque with reduced transparency, increased contrast, high contrast or forced colors. Names may change before 1.0. [→](/foundations/glass)
- DataGrid accepts `hiddenColumns`; DataGridColumnPicker is a “Columns” button that opens a checkbox menu, and it works with Table too. The menu stays open while you check columns, a `hideable: false` column and the last visible column can't be hidden, and a sorted column keeps sorting the rows while hidden. Hidden columns keep their resized width; save the choice with `onHiddenColumnsChange`. [→](/components/datagrid)
- The Glass template: a travel journal with full-bleed photos, a glass sidebar and tab bar (which shrink while scrolling), an Explore page with pins and floating filters in clear glass, a glass bottom sheet, and a glass / solid setting. Sample photos from Unsplash in AVIF. [→](/templates)
- The Landing template: a product page with monthly / yearly pricing, FAQ, testimonials and a validated sign-up form. The first screen, title, Open Graph and product JSON-LD are written into `index.html` at build time; mobile Lighthouse scores are 95 or higher in all four categories, checked in CI. [→](/templates)
- The Next.js starter template (App Router): YugenProvider in a Client Component, theme and brand stored in a cookie so the server renders the right theme (no flash), a home page that is a Server Component using Yugen components, per-page metadata and `next/font`. The SSR page links to the template. [→](/concepts/ssr)
- The Admin template: customers and orders on a mock API. DataGrid with server-side paging, sorting and filtering, a column picker, and multi-row selection for CSV export or deletion; add and edit in a Drawer with validation by react-hook-form + zod; optimistic updates that roll back with a toast on error. Includes sign-in, forgot password, OTP code entry and pages that require signing in. [→](/templates)
- The Docs template: documentation pages from Markdown files, with each folder as a section of the sidebar. The table of contents highlights the heading you're reading, Ctrl K searches titles and headings, code blocks are grouped into tabs by language, and install commands get npm / pnpm / yarn / bun tabs. Each page has its own HTML file with title, description and Open Graph, plus `sitemap.xml` and `404.html`. [→](/templates)
- The Store template: a small shop selling tea, ceramics and stationery. A product grid filtered by category and price range, with sorting and filters kept in the URL; product pages with a Carousel and color, size and quantity choices; a cart in a Sheet saved to `localStorage`; a four-step Wizard checkout with validation and an order confirmation page. Prices are formatted by language (USD or VND), and checkout is only simulated. [→](/templates)

## Improved

- The SaaS template uses real paths (`/analytics`) instead of `#/analytics`, and old links still open the right page. SaaS, Dashboard, AI chat and Glass come with deploy configuration: `_redirects` for Netlify, `vercel.json`, and `npm run build:gh-pages` for GitHub Pages; Cloudflare Pages needs nothing extra. [→](/templates)
- DataGrid: a column only needs `label`, and `renderHeaderCell` becomes optional. The hide / show logic is available on its own through `useDataGridColumnVisibility` and `getVisibleColumns`. [→](/components/datagrid)
- DataGrid and Table use tabular figures, so numbers in a column line up without an extra class. [→](/components/table)
- MenuItemCheckbox and MenuItemRadio accept `secondaryContent`, like MenuItem. [→](/components/menu)
- The Versioning page sets a rule for each number: most changes ship in patch releases, a minor only comes with new API and at least 14 days after the last one, and majors are at least 180 days apart. This applies after 0.12.0. [→](/concepts/versioning)

## Fixed

- DataGrid: when the set of columns changes, keyboard focus stays on the same column instead of jumping to whichever column now sits at that position; if the focused cell is removed, focus moves to the nearest column. [→](/components/datagrid)
- Menu, ContextMenu, Menubar and submenus: long menus scroll within the screen instead of overflowing it, so the last item can always be reached. [→](/components/contextmenu)
- Touch screens: row action buttons, subtle selection checkboxes (Table, DataGrid) and Tree item actions are always visible, since there is no hover to reveal them. [→](/components/table)

# DataGrid, an AI kit, a shadcn registry and automated tests

Adds DataGrid, an AI component kit (StreamingMarkdown, Citation, Reasoning, PromptInput), Tour, NotificationCenter, FileUpload, Stepper, TimePicker, Overflow, and Scatter and Heatmap charts. Each component can be installed with the shadcn CLI. The docs load faster and come in English, and more than 800 automated tests now run.

## New

- DataGrid: sorting, row selection, resizable columns and virtualization for 10,000 rows. [→](/components/datagrid)
- AI kit: a safe StreamingMarkdown, Citation, Reasoning, and PromptInput with attachments. [→](/components/streamingmarkdown)
- Tour, a guided tour with a spotlight, and NotificationCenter (popover or bottom sheet). [→](/components/tour)
- FileUpload, Stepper / Wizard and a form pattern with react-hook-form + zod. [→](/components/fileupload)
- TimePicker, presets for DateRangePicker, and Overflow, which hides items that don't fit. [→](/components/timepicker)
- ScatterChart, Heatmap, 100% stacked AreaChart, and zoom with a brush. [→](/components/scatterchart)
- Install components as source code with the shadcn CLI: `npx shadcn add …/r/<name>.json`. [→](/concepts/shadcn-registry)
- Theme Designer exports JSON (W3C Design Tokens, Tokens Studio). [→](/theme-designer)

## Improved

- The docs load each page lazily (first-load JS down from 970 kB to 108 kB), with an English version and a version menu. [→](/)
- A StackBlitz button on every example, and a versioning and deprecation policy. [→](/concepts/versioning)

## Fixed

- Accessibility fixes (axe on 128 pages in light and dark), Resizable dragging the wrong way in RTL, hydration mismatches with SSR, and React 19 compatibility.

# Quote, Autocomplete and a clearer SearchBox

Adds Quote for quotations with a source, and Autocomplete, a search box with suggestions and accent-insensitive filtering. The SearchBox list filtering example is redesigned.

## New

- Quote: quotations with an author and a source, in three styles (default, subtle, emphasis). [→](/components/quote)
- Autocomplete: a search box with suggestions. Accent-insensitive filtering (typing “xoai” finds “Xoài”), highlighted matches, grouped suggestions and loading from a server. [→](/components/autocomplete)

## Improved

- SearchBox: the “Filter a list” example now shows results in a list panel with a count, avatars and an empty state. [→](/components/searchbox)

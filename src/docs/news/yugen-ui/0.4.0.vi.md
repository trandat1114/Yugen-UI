# Khái niệm, RTL & tương phản cao

Tài liệu chuyên sâu kiểu Storybook, hỗ trợ hướng chữ phải-sang-trái và theme tương phản cao.

## Mới

- 16 trang Khái niệm: bắt đầu nhanh, styling, theming, slot, định vị, RTL, SSR, khả năng tiếp cận, chuyển đổi. [→](/concepts/introduction)
- Thanh công cụ Theme (Yugen / Web / Teams × Light / Dark, Tương phản cao) và công tắc LTR / RTL.
- YugenProvider — theme, brand, hướng chữ lồng được; bề mặt portal tự theo provider. [→](/concepts/theming)
- Theme Designer sinh brand ramp 16 bậc kèm kiểm tra tương phản. [→](/theme-designer)
- Motion (Fade, Scale, Slide, Collapse, Stagger), AriaLive, Focus management, CompoundButton, MenuButton, TeachingPopover…

## Sửa lỗi

- Command không còn kéo cả trang khi mount; Field gắn nhãn đúng cho nhóm control.

# CLI @yugen-ui/cli

Tạo app, thiết lập dự án và chép mã nguồn component bằng một công cụ dòng lệnh. Sửa một lỗi nhỏ của AriaLive.

## Mới

- CLI `@yugen-ui/cli`: `npm create yugen-ui@latest` tạo app từ template; `npx @yugen-ui/cli@latest init` thiết lập dự án có sẵn (gói npm hoặc mã nguồn); `add` chép component kèm phụ thuộc; `doctor` kiểm tra cấu hình. [→](/concepts/cli)

## Cải tiến

- Trang chủ có mục Tạo dự án nhanh và tab CLI trong khung cài đặt; mục Import của mỗi component có tab yugen CLI. [→](/)
- Bắt đầu nhanh, Templates và README của template dùng CLI trước; cách cài thủ công và shadcn CLI vẫn giữ. [→](/concepts/quick-start)

## Sửa lỗi

- AriaLive: announcer dự phòng (khi không có AriaLiveAnnouncer) không còn báo lỗi “window is not defined” khi hàng đợi chạy sau lúc `window` đã mất, vd. sau khi môi trường test bị gỡ. [→](/components/arialive)

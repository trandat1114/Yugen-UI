# Lệnh tạo dự án chạy được trên PowerShell

Lệnh copy từ docs chạy được trên Windows PowerShell. Gói npm không đổi.

## Sửa lỗi

- Lệnh tạo dự án dùng `npx create-yugen-ui@latest my-app --template <tên>`: PowerShell bỏ mất dấu `--` trong `npm create … -- --template` nên npm báo “Unknown cli config --template”. [→](/concepts/quick-start)
- `cd my-app` và `npm run dev` nằm trên dòng riêng thay vì nối bằng `&&` (Windows PowerShell 5.1 không chấp nhận). [→](/templates)

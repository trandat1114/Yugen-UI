# React 19 and a minimal starter

React 19 is the default, and React 18.3 is still supported. A leaner English starter, 5 new blocks, and updated docs and roadmap.

## New

- 5 new blocks: Newsletter sign-up, Quantity picker, Welcome dialog, Project progress and Who's online. [→](/blocks)

## Improved

- React 19 is the default for the docs, tests and templates. React 18.3 is still supported and tested in CI, and the end of React 18 support will be announced at least one minor release ahead. [→](/concepts/quick-start)
- Templates have short names (Starter, SaaS, Blog, Dashboard, AI chat) and one-line descriptions. The starter is a minimal English page with the Sakura and Web brands. [→](/templates)
- What's new has a tab each for yugen-ui, @yugen-ui/cli and create-yugen-ui; notes for an upcoming release carry an Upcoming label. [→](/news)
- The Introduction page is rewritten. The Community page has a roadmap by release and explains how the project is run, all in English. [→](/community)
- The docs call the CLI by its real name, `@yugen-ui/cli`, and repeat themselves less. The footer links to GitHub, npm, Discussions and Report a bug. The table of contents no longer sits right against the untranslated-page notice. [→](/concepts/cli)

## Fixed

- AvatarGroup: the accessible name of the “+N” button starts with the number it shows (WCAG 2.5.3), and `overflowLabel` is read after the count. [→](/components/avatargroup)

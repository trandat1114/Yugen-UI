# Sidebar collapse button that stays put

The sidebar collapse button no longer moves when you press it, so a second click undoes the first without looking for the button.

## Fixed

- AppShell: a `SidebarTrigger` inside `Sidebar` (last item of `SidebarFooter`) is the wide-screen collapse button. It sits in the rail's icon column, so it keeps the same position expanded and collapsed. With `collapsible="offcanvas"` it stays at that corner while the sidebar is hidden.
- When a shell has that button, the `SidebarTrigger` in the top bar only opens the Drawer on narrow frames. No duplicate button, no layout shift on the first paint.
- The Dashboard, SaaS, Admin, AI chat and Docs templates and the docs site use it (#482).

# Replaceable UI strings, English docs and new templates

Every built-in string in the components can be changed through YugenProvider, and an English set is included. The docs are fully available in English, with real URLs and prerendered HTML. Dashboard and AI chat become complete apps, and every template comes in two languages.

## New

- YugenProvider accepts `messages` and `locale`: change button labels, `aria-label` text and screen reader announcements for every component, by namespace; `messagesEn` switches everything to English. A component's own label props still take priority; Vietnamese stays the default. [→](/concepts/localization)
- Component pages have a Messages section listing each key with its Vietnamese default and English version. [→](/components/toast)
- English docs for every page under `/en/`: concepts, 113 components, Foundations, Blocks and Theme Designer. Path-based URLs, prerendered HTML for each page, a sitemap with `hreflang` and Open Graph images of their own; a new SEO page. [→](/concepts/seo)
- The Dashboard template (4 pages, one date range for every chart, DataGrid with CSV export) and AI chat (conversation list, streamed replies you can stop, connects to your own backend) become complete apps; SaaS, Blog and the new templates come in English and Vietnamese (`create --lang`). [→](/templates)

## Improved

- Skeleton (wave) and the indeterminate ProgressBar animate with transforms, so they no longer repaint every frame; new `animate-sweep` and `animate-indeterminate-slide` utilities. [→](/components/skeleton)
- Faster with large data or frequent updates: Chart, DataGrid, Tree, List, Combobox, TagPicker, Autocomplete, MessageScroller, StreamingMarkdown, Carousel and PageProgress. [→](/components/datagrid)
- Templates load each page on demand: the first load of SaaS is about a quarter smaller. CI builds and checks every template against the PR's own yugen-ui build (bundle size, console errors, axe). [→](/templates)
- Lighter docs: first-load JS is down by more than half and the home page has fewer elements; the cherry blossoms on the home page are no longer clipped.

## Fixed

- Calendar: in English, day buttons name the day with a plain number ("October 1, 2026" instead of "October 1st"), matching the number shown on the button, so voice control can select the day (WCAG 2.5.3). [→](/components/calendar)

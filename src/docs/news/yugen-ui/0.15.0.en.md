# Consistent prop names and a lighter install before 1.0

The API review before 1.0 gave a few components the names the rest of the library already uses. The old names keep working until 1.0 and warn once in development. Installing `yugen-ui` no longer pulls in a 180 MB icon package, and React 19 is now required.

## New

- **Typeset**: tune Prose's fonts, size, line height, block spacing and line length on real content, then copy the CSS. Prose now reads these from CSS variables, and the theme has four presets (`yugen-prose-docs`, `-article`, `-chat`, `-compact`). [→](/typeset)
- Consistent prop names, from the API review before 1.0: Carousel `gap="medium"` (full size names) and `loop`, Tree `onSelectionChange`, DatePicker and DateRangePicker `onValueChange`, List `appearance`, RatingDisplay `showValue`, toast `dismissible`, CarouselNavContainer `previousLabel`, Autocomplete `noResultsText`, and `breakpoint` tokens (`"3xl"`) on Sheet and NotificationCenter, as on AppShell. TimePicker gains `onValueChange`, Carousel `activeIndex` / `defaultActiveIndex` and Stepper `defaultActiveStep`. The old names keep working until 1.0 and print one warning in development. [→](/concepts/versioning#deprecation)

## Improved

- Yugen Labs: StreamingMarkdown, Citation, MessageScroller, CodeBlock, PageProgress, AsyncContent / ErrorState and useOptimisticList leave Labs and follow SemVer. The rest stays experimental, and their pages say so. [→](/concepts/versioning#labs)
- Components are plain function components that take `ref` as a prop, the React 19 way, instead of `forwardRef` wrappers. Refs work as before and `React.ComponentRef<typeof Button>` still gives the element type. A callback ref that returns a cleanup function now gets it called, also on components that keep their own ref (Carousel, Sheet, Toolbar…). [→](/concepts/browser-support)

## Breaking

- `yugen-ui` no longer installs `@fluentui/react-icons` (about 180 MB). The icons inside components ship with the library as small SVGs and look the same. If your app imports icons from `@fluentui/react-icons`, add it to your dependencies: `npm i @fluentui/react-icons`. Other icon sets such as `lucide-react` also fit icon slots. [→](/concepts/browser-support)
- React 19 or later is required: `react` / `react-dom` `>=19`. React 18.3 was supported through 0.14 and no longer gets fixes upstream. Apps on React 18 can stay on yugen-ui 0.14 until they upgrade. [→](/concepts/quick-start#requirements)

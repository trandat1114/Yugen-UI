# Consistent prop names before 1.0

The API review before 1.0 gave a few components the names the rest of the library already uses. The old names keep working until 1.0 and warn once in development.

## New

- Consistent prop names, from the API review before 1.0: Carousel `gap="medium"` (full size names) and `loop`, Tree `onSelectionChange`, DatePicker and DateRangePicker `onValueChange`, List `appearance`, RatingDisplay `showValue`, toast `dismissible`, CarouselNavContainer `previousLabel`, Autocomplete `noResultsText`, and `breakpoint` tokens (`"3xl"`) on Sheet and NotificationCenter, as on AppShell. TimePicker gains `onValueChange`, Carousel `activeIndex` / `defaultActiveIndex` and Stepper `defaultActiveStep`. The old names keep working until 1.0 and print one warning in development.

# GitHub Sponsors support flow

Yugen UI now includes GitHub Sponsors as the international support option. GitHub Sponsors contributions can be recorded automatically from signed sponsorship events: public sponsors may appear by GitHub handle, while private sponsorships stay anonymous. On `/support`, VietQR and GitHub Sponsors sit side by side as two equal options; VietQR still uses the manual acknowledgement form and reconciliation flow. [→](/support)

## Improved

- The `/support` page adds GitHub Sponsors for international contributions. Signed sponsorship events can add or remove a verified recognition automatically; public sponsorships may show a GitHub handle, while private sponsorships remain anonymous. VietQR remains available with its manual acknowledgement and reconciliation flow. [→](/support)
- `/support`: VietQR (VND) and GitHub Sponsors (international) share one card layout with an icon, three steps and a main panel; on wide screens they sit side by side at the same height. [→](/support)
- The note under the page title now says GitHub Sponsors is open. The VietQR acknowledgement form is marked optional and uses two columns on wide screens. [→](/support)

## Fixed

- The VietQR code keeps its white background in dark mode, and the image reserves its real aspect ratio while it loads. [→](/support)

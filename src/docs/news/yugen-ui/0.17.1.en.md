# GitHub Sponsors support flow

Yugen UI now includes GitHub Sponsors as the international support option. GitHub Sponsors contributions can be recorded automatically from signed sponsorship events: public sponsors may appear by GitHub handle, while private sponsorships stay anonymous. VietQR remains available and still uses the manual acknowledgement form and reconciliation flow. [→](/support)

## Improved

- The `/support` page adds GitHub Sponsors for international contributions. Signed sponsorship events can add or remove a verified recognition automatically; public sponsorships may show a GitHub handle, while private sponsorships remain anonymous. VietQR remains available with its manual acknowledgement and reconciliation flow. [→](/support)

# Concepts, RTL and high contrast

In-depth docs in the style of Storybook, support for right-to-left text and a high contrast theme.

## New

- 16 Concepts pages: quick start, styling, theming, slots, positioning, RTL, SSR, accessibility and migration. [→](/concepts/introduction)
- A Theme toolbar (Yugen / Web / Teams × Light / Dark, High contrast) and an LTR / RTL switch.
- YugenProvider: theme, brand and text direction that can be nested; portaled surfaces follow their provider. [→](/concepts/theming)
- Theme Designer generates a 16-step brand ramp with contrast checks. [→](/theme-designer)
- Motion (Fade, Scale, Slide, Collapse, Stagger), AriaLive, focus management, CompoundButton, MenuButton, TeachingPopover and more.

## Fixed

- Command no longer scrolls the whole page when it mounts; Field labels groups of controls correctly.

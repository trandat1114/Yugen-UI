# Templates, one-command shadcn init and SEO

A Templates page with three new templates (starter, SaaS and a Markdown blog), each created with one command. The shadcn CLI installs the theme, `cn()` and YugenProvider in one step. Quick start is down to one command, and the docs start to support SEO.

## Breaking

- shadcn registry: components no longer install the theme on their own. Run `init` once per project, or add `…/r/theme.json` along with your components. The npm package is unchanged. [→](/concepts/shadcn-registry)

## New

- Templates page: live previews, and a new project in one command (`npx giget … --install`) or on StackBlitz. [→](/templates)
- `vite-starter`: a blank start with a remembered theme, no flash on load, an `@/` alias, basic SEO and a 幽玄 cherry blossom welcome page. [→](/templates)
- `vite-saas`: an 8-page app with a sidebar, a Ctrl K command palette and notifications. `vite-blog`: a Markdown blog with an HTML file per post, `sitemap.xml` and `rss.xml`. [→](/templates)
- shadcn CLI: `npx shadcn@latest init …/r/init.json` (Next.js: `init-next.json`) creates `components.json`, copies the theme, `cn()` and YugenProvider, and adds the `@import` to your CSS. [→](/concepts/shadcn-registry)

## Improved

- Quick start: one command from a template, or three steps for an existing project (install the package, add one line of CSS, add YugenProvider). [→](/concepts/quick-start)
- Docs: a title and description for each page, Open Graph with a link preview image, and JSON-LD. A new SEO roadmap is on the Community page. [→](/community)
- The Open in StackBlitz button shows on every component example. [→](/components/button)

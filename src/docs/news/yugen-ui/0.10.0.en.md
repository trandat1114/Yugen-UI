# Numeric spacing, Theme Designer and a Motion page

Spacing uses Tailwind's numeric scale (the upper-case aliases are deprecated), and `cn()` uses tailwind-merge 3. The docs get a multi-axis Theme Designer, a new Motion page and a resizable sidebar.

## New

- Theme Designer: besides the brand color, you can pick the corner radius, density, font and root font size, neutral colors, elevation and motion, each with a few steps checked for contrast and target size. Preview in light, dark, high contrast and RTL; the exported CSS includes every choice, and a share link keeps your settings. [→](/theme-designer)
- The Motion page is rewritten and available in English: tokens and `animate-*`, the motion of each component with live demos, a playground that compares two settings, a reduced motion preview, choreography and performance. [→](/foundations/motion)
- Docs: drag the sidebar edge to change its width (240–400px, arrow keys, double-click to reset) or collapse it to icons; the state is kept after a reload.

## Improved

- Components, examples, templates and the registry use numeric spacing (`p-3`, `gap-2`) instead of the upper-case aliases (`p-M`, `gap-S`). Nothing changes at a 16px root font size; the numeric scale is in rem, so it follows the browser's font size. [→](/concepts/styling)
- The upper-case spacing aliases (`p-M`, `gap-SNudge`…) in `theme.css` and `cn()` are deprecated and keep working until 1.0. Rename them as XXS → 0.5, XS → 1, SNudge → 1.5, S → 2, MNudge → 2.5, M → 3, L → 4, XL → 5, XXL → 6, XXXL → 8. [→](/concepts/styling)
- The Form example with react-hook-form + zod is written for zod 4 (`z.email()`, the `error` parameter) and `@hookform/resolvers` 6; it needs zod 4 or later. [→](/components/formvalidation)

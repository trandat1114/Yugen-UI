# Yugen UI is born: Sakura 桜

Renamed to Yugen UI, with a cherry blossom brand, 47 new components and a Blocks page.

## Breaking

- The default brand changes from Communication Blue to Sakura #C2347A (blue is still available with `data-brand="web"`).

## New

- 47 new components, following the Fluent 2 and shadcn/ui catalogs. [→](/)
- Blocks: ready-made page sections that you copy as whole files. [→](/blocks)
- Sakura, Dusk and Sunset gradients, and a cherry blossom enso logo.

# Tên prop thống nhất và bản cài nhẹ hơn trước 1.0

Đợt rà soát API trước 1.0 đổi tên vài prop cho giống phần còn lại của thư viện. Tên cũ vẫn chạy tới 1.0 và cảnh báo một lần khi đang phát triển. Cài `yugen-ui` không còn kéo theo gói icon 180 MB, và từ bản này cần React 19.

## Mới

- **Typeset**: chỉnh font, cỡ chữ, line-height, khoảng cách khối và độ rộng dòng của Prose trên nội dung thật, rồi copy CSS. Prose giờ đọc các giá trị này từ biến CSS, và theme có sẵn bốn preset (`yugen-prose-docs`, `-article`, `-chat`, `-compact`). [→](/typeset)
- `YugenProvider` nhận `defaults` và `density`. `defaults={{ Button: { shape: "circular" } }}` đặt prop cho mọi instance trong vùng giao diện đó, prop đặt trên instance vẫn thắng. `density="compact"` cho control mặc định size small và thu hẹp spacing; `"comfortable"` nới rộng spacing. [→](/concepts/theming#defaults)
- Yugen Labs: `glassNavigationDefaults` đổi mọi component điều hướng có glass (Toolbar, TabsList, Nav, menu, popover, tooltip, dialog, drawer và sheet) sang `material="glass"` từ một chỗ: `<YugenProvider defaults={glassNavigationDefaults}>`. [→](/foundations/glass#provider-default)
- Tên prop thống nhất, theo đợt rà soát API trước 1.0: Carousel `gap="medium"` (tên cỡ đầy đủ) và `loop`, Tree `onSelectionChange`, DatePicker và DateRangePicker `onValueChange`, List `appearance`, RatingDisplay `showValue`, toast `dismissible`, CarouselNavContainer `previousLabel`, Autocomplete `noResultsText`, và `breakpoint` dạng token (`"3xl"`) cho Sheet và NotificationCenter như AppShell. TimePicker thêm `onValueChange`, Carousel thêm `activeIndex` / `defaultActiveIndex`, Stepper thêm `defaultActiveStep`. Tên cũ vẫn chạy tới 1.0, kèm một cảnh báo khi phát triển. [→](/concepts/versioning#deprecation)

## Cải tiến

- Yugen Labs: StreamingMarkdown, Citation, MessageScroller, CodeBlock, PageProgress, AsyncContent / ErrorState và useOptimisticList rời Labs và theo SemVer. Phần còn lại vẫn là thử nghiệm, và trang của chúng có ghi rõ. [→](/concepts/versioning#labs)
- Component giờ là hàm thường nhận `ref` như một prop theo cách của React 19, thay cho `forwardRef`. Ref vẫn dùng như cũ và `React.ComponentRef<typeof Button>` vẫn cho đúng kiểu phần tử. Callback ref trả về hàm cleanup giờ được gọi hàm đó, kể cả ở component tự giữ ref riêng (Carousel, Sheet, Toolbar…). [→](/concepts/browser-support)

## Sửa lỗi

- Markdown, StreamingMarkdown và CodeBlock vẫn nhanh với input độc hại: lồng quá sâu không còn làm tràn stack, và chuỗi dài `[`, `*` hay `${` chưa đóng không còn mất hàng giây để phân tích. Trang Bảo mật mới ghi Yugen UI làm sạch những gì và app còn phải tự làm gì. [→](/concepts/security)

## Thay đổi lớn

- `yugen-ui` không còn cài kèm `@fluentui/react-icons` (khoảng 180 MB). Icon bên trong component đi kèm thư viện dưới dạng SVG nhỏ, hiển thị như cũ. App nào import icon từ `@fluentui/react-icons` thì thêm gói đó vào dependencies: `npm i @fluentui/react-icons`. Bộ icon khác như `lucide-react` cũng vừa các ô icon. [→](/concepts/browser-support)
- Cần React 19 trở lên: `react` / `react-dom` `>=19`. React 18.3 được hỗ trợ đến hết 0.14 và không còn nhận bản sửa lỗi từ React. App còn dùng React 18 có thể giữ yugen-ui 0.14 tới khi nâng cấp. [→](/concepts/quick-start#requirements)

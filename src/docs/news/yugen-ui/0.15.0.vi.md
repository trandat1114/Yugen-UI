# Tên prop thống nhất trước 1.0

Đợt rà soát API trước 1.0 đổi tên vài prop cho giống phần còn lại của thư viện. Tên cũ vẫn chạy tới 1.0 và cảnh báo một lần khi đang phát triển.

## Mới

- Tên prop thống nhất, theo đợt rà soát API trước 1.0: Carousel `gap="medium"` (tên cỡ đầy đủ) và `loop`, Tree `onSelectionChange`, DatePicker và DateRangePicker `onValueChange`, List `appearance`, RatingDisplay `showValue`, toast `dismissible`, CarouselNavContainer `previousLabel`, Autocomplete `noResultsText`, và `breakpoint` dạng token (`"3xl"`) cho Sheet và NotificationCenter như AppShell. TimePicker thêm `onValueChange`, Carousel thêm `activeIndex` / `defaultActiveIndex`, Stepper thêm `defaultActiveStep`. Tên cũ vẫn chạy tới 1.0, kèm một cảnh báo khi phát triển.

# Create-project commands work in PowerShell

Commands copied from the docs run in Windows PowerShell. The npm package is unchanged.

## Fixed

- The create-project command is now `npx create-yugen-ui@latest my-app --template <name>`. PowerShell dropped the `--` in `npm create … -- --template`, so npm reported “Unknown cli config --template”. [→](/concepts/quick-start)
- `cd my-app` and `npm run dev` are on separate lines instead of being joined with `&&`, which Windows PowerShell 5.1 does not accept. [→](/templates)

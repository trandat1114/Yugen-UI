# Yugen Labs, the npm package and community

Components that go beyond Fluent 2 (Trace, Questionnaire, Message Scroller, Code Block, Chart and an adaptive Sheet), plus a Wait UX layer, the npm build and a Community page.

## New

- Trace: shows each step of an AI agent, a CI run or a deployment. [→](/components/trace)
- Questionnaire: multi-step surveys with one question per screen. [→](/components/questionnaire)
- Message Scroller, Message Bubble, Typing Indicator and Chat Composer for chat interfaces. [→](/components/messagescroller)
- Code Block with highlighting, line numbers, diffs, file tabs and package manager tabs. [→](/components/codeblock)
- Charts (Bar, Line, Area, Donut, Sparkline, StatTile), built with a data visualization process and validated colors. [→](/components/barchart)
- Sheet: a side panel on desktop, a draggable bottom sheet on mobile. [→](/components/sheet)
- Wait UX: the Button loading state, `useSpinDelay`, PageProgress, AsyncContent, ErrorState and ready-made Skeletons. [→](/concepts/wait-ux)
- The `yugen-ui` npm package with `theme.css` (Tailwind v4), `styles.css` (no Tailwind needed) and type declarations. [→](/concepts/quick-start)
- Community and What's new pages. [→](/community)

## Improved

- Carousel gets looping, autoplay with progress, peek and thumbnails; Accordion adds separated and outline styles. [→](/components/carousel)
- Resizable gets collapsible panels and can save its layout. [→](/components/resizable)

## Fixed

- All Tailwind classes are in canonical form (checked by the `lint:classes` script), so the `suggestCanonicalClasses` warnings are gone.

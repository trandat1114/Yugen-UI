# Sửa path beacon analytics production

Beacon analytics production nay luôn gửi đường dẫn theo đúng hợp đồng của collector.

## Sửa lỗi

- Chuẩn hoá đường dẫn của page view và sự kiện giao diện trước khi gửi tới collector: trang chủ dùng `/`, còn các trang ngôn ngữ luôn có dấu `/` đầu, tránh lỗi `400` do payload không hợp đồng.

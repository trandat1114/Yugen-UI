# The @yugen-ui/cli command line tool

Create apps, set up projects and copy component source with one command line tool. Also a small AriaLive fix.

## New

- `@yugen-ui/cli`: `npm create yugen-ui@latest` creates an app from a template; `npx @yugen-ui/cli@latest init` sets up an existing project (npm package or source code); `add` copies components with their dependencies; `doctor` checks your setup. [→](/concepts/cli)

## Improved

- The home page has a Start a new project section and a CLI tab in the install box; each component's Import section has a yugen CLI tab. [→](/)
- Quick start, Templates and the template READMEs show the CLI first; manual setup and the shadcn CLI are still there. [→](/concepts/quick-start)

## Fixed

- AriaLive: the fallback announcer (used when there is no AriaLiveAnnouncer) no longer throws “window is not defined” when its queue runs after `window` is gone, for example after a test environment is torn down. [→](/components/arialive)

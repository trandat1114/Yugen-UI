# Native form controls, Form, an optional date stack and more charts

This release brings three of the breaking changes planned for 1.0 forward, so they can be tried before 1.0: native checkboxes and radios, date components in their own entry, and design tokens in a cascade layer. It also adds Form, three chart types, BentoGrid and a Timeline that follows the page scroll. Sizes are gzip.

## Breaking

- Checkbox, Switch and Radio render a native `<input>` instead of a Radix `<button>`. Hydrating 500 checkboxes takes 49 ms instead of 181, and the value goes with the form, FormData and autofill without a hidden copy. `ref` now points to an `HTMLInputElement`; `data-state` stays, but selectors that name the element (`button[data-state=checked]`) need `input` or `:checked`. [→](/components/checkbox)
- Calendar, DatePicker, DateRangePicker and DateTimePicker move to `yugen-ui/dates`, and `react-day-picker` becomes an optional peer: run `npm i react-day-picker` and change the import. An app without date components installs 3 packages (about 12 MB) less, and `import *` from the root goes from 325.3 to 298.5 kB. In Vietnamese, add `calendar: calendarMessagesVi` (from `yugen-ui/dates`) to `messages`. [→](/components/datepicker)
- Design tokens are declared in the `theme` cascade layer, so your own `:root { --colorBrandBackground: … }` wins whatever the file order. `theme-core.css` keeps the Sakura brand; the web and Teams brands moved to `yugen-ui/tokens/brands.css` (`yugen css` adds it) and chart tokens to `yugen-ui/tokens/charts.css`. [→](/concepts/styling#lean-css)

## New

- `Form` runs a React 19 action. Before it, the controls' constraints (`required`, `type`, `pattern`, `min`…) are checked with English or Vietnamese messages; errors show in the `Field` of the same `name`, what people typed stays, and focus moves to the first invalid control. `FormErrorSummary` lists the errors as links to each control. [→](/components/form)
- `yugen-ui/form`: `HookForm` connects react-hook-form to `Field`, `FormErrorSummary` and the submit `Button`, and `standardSchemaResolver` validates with zod 4, valibot or arktype. react-hook-form is an optional peer that only this entry imports. [→](/components/form)
- `RadarChart` compares several series over the same axes, with a polygon, circle or no grid, dots, lines only and a legend that hides a series. [→](/components/radarchart)
- `PieChart` draws solid slices with the data, legend and table of DonutChart, and `RadialChart` draws gauges, tracks, partial arcs and stacked values. Both are plain SVG with keyboard navigation and a data table. [→](/components/radialchart)
- `LineChart` and `AreaChart` take `curve="step"` for values that change in steps. [→](/components/linechart)
- `BentoGrid` and `BentoGridItem`: a CSS grid of cards with responsive spans, link cards and slots for media, icon and actions. Nothing is measured in JavaScript. [→](/components/bentogrid)
- Timeline `progress`: a rail fills as the page scrolls, items are complete, current or upcoming, and the current one gets `aria-current`. `dateLayout="sticky"` puts the dates in a column of their own. [→](/components/timeline)
- TeachingPopover `focus="spotlight"` dims the rest of the page and keeps focus in the popover until it closes. [→](/components/teachingpopover)
- `yugen-ui/components.css` embeds Yugen in a page whose CSS you don't own (a CMS, a widget): no global reset and no styles for `html` or `body`. [→](/concepts/styling#lean-css)
- Persona takes several people (`avatars`), shown as an AvatarGroup. Avatar takes `image` options (`srcSet`, `sizes`, `loading`…) and `renderImage` for a framework image component such as Next.js `<Image>`. [→](/components/persona)

## Improved

- Calendar and Resizable have prop types of their own, so the published types no longer import react-day-picker or react-resizable-panels. Calendar props outside `CalendarProps` (`classNames`, `components`, `onDayClick`…) still work with a development warning until 1.0. [→](/components/calendar)
- Avatar no longer uses `@radix-ui/react-avatar` and Switch no longer uses `@radix-ui/react-switch`. The `<img>` is in the server HTML, so a photo starts loading before hydration. [→](/components/avatar)
- DataGrid goes from 28 to 20.3 kB with the native checkboxes.
- The focus ring is an outline only: focusing an element never changes its shape.

## Fixed

- StreamingMarkdown no longer drops a character when a paragraph with an unclosed `` ` ``, `**` or `[` stops being the last block. [→](/components/streamingmarkdown)

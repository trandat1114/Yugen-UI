# More chart forms, clearer comparisons and faster interactions

The next chart milestone expands the SVG chart family with pie and radial primitives, step interpolation, shared accessible workflows and shadcn-inspired examples. The implementation keeps chart geometry local, tree-shakable and measurable instead of adding a rendering runtime.

## New

- `PieChart` reuses the DonutChart data, legend, locale and table contract for solid pie slices, optional separators and accessible keyboard navigation. [→](/components/chart)
- `RadialChart` supports gauge values, tracks, partial arcs, center labels and stacked segments with a small SVG-only implementation. [→](/components/chart)
- `LineChart` and `AreaChart` accept `curve="step"` for discrete or state-transition data while retaining `linear` and `monotone`. [→](/components/chart)
- Chart examples now track the Area, Bar, Line, Pie, Radar, Radial and Tooltip patterns from the shadcn gallery, including responsive, high-contrast and reduced-motion cases. [→](/components/chart)

## Improved

- Chart interactions keep geometry and formatted rows out of the hover hot path; optional tables are still built only when opened.
- Pie, radial and existing chart marks share localized formatting, texture tokens, keyboard focus and accessible table fallbacks.

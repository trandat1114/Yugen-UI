# Luồng ủng hộ qua GitHub Sponsors

Yugen UI thêm GitHub Sponsors làm lựa chọn ủng hộ quốc tế. Đóng góp qua GitHub Sponsors có thể được tự động ghi nhận từ sự kiện sponsorship đã xác thực: sponsor công khai có thể hiện GitHub handle, còn sponsorship riêng tư vẫn được ẩn danh. Trên trang `/support`, VietQR và GitHub Sponsors đứng cạnh nhau như hai lựa chọn ngang hàng; VietQR vẫn dùng form ghi nhận cùng quy trình đối soát thủ công. [→](/support)

## Cải tiến

- Trang `/support` thêm GitHub Sponsors cho đóng góp quốc tế. Sự kiện sponsorship đã xác thực có thể tự động thêm hoặc gỡ ghi nhận; sponsorship công khai có thể hiện GitHub handle, còn sponsorship riêng tư vẫn ẩn danh. VietQR vẫn hoạt động với form ghi nhận và quy trình đối soát thủ công. [→](/support)
- `/support`: VietQR (VND) và GitHub Sponsors (quốc tế) dùng chung một kiểu card gồm biểu tượng, ba bước và khối chính; trên màn rộng hai card đứng cạnh nhau, cao bằng nhau. [→](/support)
- Thông báo dưới tiêu đề trang báo đã có GitHub Sponsors. Form ghi nhận VietQR ghi rõ là không bắt buộc và chia hai cột trên màn rộng. [→](/support)

## Sửa lỗi

- Mã VietQR giữ nền trắng ở theme tối, và ảnh giữ đúng tỷ lệ khi đang tải. [→](/support)

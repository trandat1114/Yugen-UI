# Luồng ủng hộ qua GitHub Sponsors

Yugen UI thêm GitHub Sponsors làm lựa chọn ủng hộ quốc tế. Đóng góp qua GitHub Sponsors có thể được tự động ghi nhận từ sự kiện sponsorship đã xác thực: sponsor công khai có thể hiện GitHub handle, còn sponsorship riêng tư vẫn được ẩn danh. VietQR vẫn hoạt động và tiếp tục dùng form ghi nhận cùng quy trình đối soát thủ công. [→](/support)

## Cải tiến

- Trang `/support` thêm GitHub Sponsors cho đóng góp quốc tế. Sự kiện sponsorship đã xác thực có thể tự động thêm hoặc gỡ ghi nhận; sponsorship công khai có thể hiện GitHub handle, còn sponsorship riêng tư vẫn ẩn danh. VietQR vẫn hoạt động với form ghi nhận và quy trình đối soát thủ công. [→](/support)

# Template dựng trên AppShell, bảng Kanban trong template Admin

Chín template dựng trên AppShell của `yugen-ui` 0.14.0 thay cho khung tự viết. Template Admin có thêm trang Bảng: công việc kéo thả giữa các cột.

## Cải tiến

- Template starter, saas, blog, dashboard, ai-chat, admin, docs, store và landing: sidebar thu về icon hoặc mở thành Drawer trên màn hẹp, Ctrl+B / ⌘B, skip link tới nội dung chính. Template ghim `yugen-ui@^0.14.0`. [→](/templates)
- Template admin: trang Bảng (Kanban) dùng Sortable, kéo thả bằng chuột, cảm ứng hoặc bàn phím; thứ tự được lưu khi thả, yêu cầu lỗi thì trả về chỗ cũ và báo bằng toast. [→](/components/sortable)

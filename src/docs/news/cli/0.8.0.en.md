# yugen css: only the CSS of the components you import

`yugen css` writes the CSS for the components your code imports instead of every component in the package. On the templates the gzipped CSS goes from about 26 kB to 12–20 kB. `init` sets it up, `add` keeps it up to date and `doctor` checks it.

## New

- `yugen css --watch` keeps `yugen-ui.css` current as component imports change. The Vite plugin (`@yugen-ui/cli/vite`) runs before a build and watches `add`, `change` and `unlink` during dev; `init` wires it into an existing Vite project, and the Next.js template runs the watcher beside `next dev`. [→](/concepts/cli#css)
- `yugen css` reads the imports from `yugen-ui` and `yugen-ui/<Folder>` in your code and writes `yugen-ui.css`: `theme-core.css` plus one `sources/<Folder>.css` per component folder. On the templates the CSS goes from about 26 kB to 12–20 kB gzip (−24% to −54%). Examples inside strings, comments or JSX text don't count; `import * as` and `import()` of the root fall back to `theme.css`. `--check` exits with 1 when the file is out of date, for CI or a `prebuild` script. [→](/concepts/cli#css)
- `yugen css --precompile` compiles plain CSS for apps without Tailwind, with the project's own `tailwindcss`, `@tailwindcss/node` and `@tailwindcss/oxide`, and replaces `yugen-ui/styles.css`: 26.8 kB down to 12.8–21.1 kB on the templates. The CLI does not bundle Tailwind. [→](/concepts/cli#css)

## Improved

- `init` (package mode, Tailwind CSS v4) writes `yugen-ui.css` and imports it instead of `yugen-ui/theme.css`. A CSS file that already imports `theme.css` is left as it is. In package mode, `add` adds the component to `yugen-ui.css` when the app has one. [→](/concepts/cli#init)
- `doctor` warns when `yugen-ui.css` is out of date or not imported, and names the components imported without their `sources/<Folder>.css`. [→](/concepts/cli#doctor)
- No runtime dependencies: prompts and colors use Node's own `readline` and `util.styleText` instead of `@clack/prompts` and `picocolors`, so `npm create yugen-ui` installs 2 packages instead of 9. Colors follow `NO_COLOR` / `FORCE_COLOR`. [→](/concepts/cli)
- The bundled templates ship their `package.json` as `_package.json`, and `create` renames it back. Tools that scan the package no longer count every template's dependencies as dependencies of the CLI.
- `create --ref` no longer reads `GITHUB_TOKEN` or `GH_TOKEN`: its two GitHub API calls stay well under the anonymous limit.

## Fixed

- `doctor` no longer reports that the theme is not imported when the app imports `yugen-ui/theme-core.css`. [→](/concepts/cli#doctor)
- `add` and `update` refuse registry files whose path leaves the components or lib folder (`..`, absolute paths), and dependencies that are not an npm package name with an optional version range. On Windows, the package manager that started the CLI now runs without a shell.

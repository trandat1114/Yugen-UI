# diff, update, remove, theme and new templates

Update copied code from the registry, remove components, generate brand colors and wrap the app in YugenProvider automatically.

## New

- `yugen diff` and `yugen update`: compare copied code with the registry, review the diff, then apply the new version (`update` asks before writing, `--dry-run` only shows the changes). [→](/concepts/cli)
- `yugen remove`: deletes a component's files and keeps any file that is still imported elsewhere. [→](/concepts/cli)
- `yugen theme --brand <hex>`: generates a brand ramp into `yugen-brand.css` (the same algorithm as the Theme Designer) and warns when contrast is below 4.5:1. [→](/concepts/cli)
- The Dashboard template (4 pages, DataGrid with CSV export) and the AI chat template (conversation list, streamed replies, your own backend) are now full apps. With `--lang en`, the built-in component strings are in English too; `--lang vi` adds nothing extra. Templates use `yugen-ui` 0.11. [→](/templates)

## Improved

- `yugen init` wraps the app in YugenProvider (`main.tsx` in Vite, `app/layout.tsx` in Next.js); `create --ref` takes the templates from a branch or tag. [→](/concepts/cli)
- `create --lang en|vi` now also works with the SaaS and Blog templates, and removes the other language's `src/content/<lang>/` folder (the blog's posts), not just its `.ts` file. [→](/templates)
- `create --lang` also writes that language's title, description and Open Graph tags into `index.html`, so link previews and search engines see the right language. [→](/templates)

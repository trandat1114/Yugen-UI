# yugen css: chỉ CSS của các component bạn import

`yugen css` ghi CSS cho các component mà code của bạn import thay vì mọi component trong gói. Trên các template, CSS sau gzip từ khoảng 26 kB còn 12–20 kB. `init` cài sẵn, `add` giữ file luôn mới và `doctor` kiểm tra nó.

## Mới

- `yugen css --watch` giữ `yugen-ui.css` luôn mới khi import component thay đổi. Plugin Vite (`@yugen-ui/cli/vite`) chạy trước build và theo dõi `add`, `change`, `unlink` khi dev; `init` tự gắn plugin vào dự án Vite có sẵn, còn template Next.js chạy watcher cùng `next dev`. [→](/concepts/cli#css)
- `yugen css` đọc các import từ `yugen-ui` và `yugen-ui/<Thư mục>` trong code của bạn rồi ghi `yugen-ui.css`: `theme-core.css` cộng một dòng `sources/<Thư mục>.css` cho mỗi thư mục component. Trên các template, CSS từ khoảng 26 kB còn 12–20 kB gzip (−24% đến −54%). Ví dụ viết trong chuỗi, comment hay chữ trong JSX không được tính; `import * as` và `import()` từ gốc gói thì dùng lại `theme.css`. `--check` thoát với mã 1 khi file đã cũ, dùng cho CI hoặc script `prebuild`. [→](/concepts/cli#css)
- `yugen css --precompile` biên dịch CSS thuần cho ứng dụng không dùng Tailwind, bằng `tailwindcss`, `@tailwindcss/node` và `@tailwindcss/oxide` của chính dự án, rồi thay `yugen-ui/styles.css`: từ 26.8 kB còn 12.8–21.1 kB trên các template. CLI không mang theo Tailwind. [→](/concepts/cli#css)

## Cải tiến

- `init` (chế độ package, Tailwind CSS v4) ghi `yugen-ui.css` và import file này thay cho `yugen-ui/theme.css`. File CSS đã import `theme.css` được giữ nguyên. Ở chế độ package, `add` thêm component vào `yugen-ui.css` khi ứng dụng có file này. [→](/concepts/cli#init)
- `doctor` cảnh báo khi `yugen-ui.css` đã cũ hoặc chưa được import, và nêu tên các component được import mà thiếu `sources/<Thư mục>.css`. [→](/concepts/cli#doctor)
- Không còn dependency lúc chạy: prompt và màu dùng `readline` và `util.styleText` có sẵn trong Node thay cho `@clack/prompts` và `picocolors`, nên `npm create yugen-ui` chỉ cài 2 gói thay vì 9. Màu theo `NO_COLOR` / `FORCE_COLOR`. [→](/concepts/cli)
- Template đóng gói kèm CLI lưu `package.json` thành `_package.json`, `create` đổi lại tên khi chép ra. Công cụ quét gói không còn tính dependency của mọi template vào CLI.
- `create --ref` không còn đọc `GITHUB_TOKEN` hay `GH_TOKEN`: hai lời gọi GitHub API mỗi lần chạy nằm xa dưới giới hạn khi chưa đăng nhập.

## Sửa lỗi

- `doctor` không còn báo theme chưa được import khi ứng dụng import `yugen-ui/theme-core.css`. [→](/concepts/cli#doctor)
- `add` và `update` từ chối file của registry có đường dẫn ra ngoài thư mục components hoặc lib (`..`, đường dẫn tuyệt đối), và dependency không phải tên gói npm kèm khoảng phiên bản. Trên Windows, trình quản lý gói đã chạy CLI giờ được gọi không qua shell.

# diff, update, remove, theme và template mới

Cập nhật mã đã chép theo registry, gỡ component, sinh màu thương hiệu và tự bọc YugenProvider.

## Mới

- `yugen diff` và `yugen update`: so mã đã chép với registry, xem diff rồi áp bản mới (`update` hỏi lại trước khi ghi, `--dry-run` chỉ xem). [→](/concepts/cli)
- `yugen remove`: xoá file của component, giữ lại file còn được import ở nơi khác. [→](/concepts/cli)
- `yugen theme --brand <hex>`: sinh brand ramp vào `yugen-brand.css` (cùng thuật toán Theme Designer) và cảnh báo khi tương phản dưới 4.5:1. [→](/concepts/cli)
- Template Dashboard (4 trang, DataGrid xuất CSV) và AI chat (danh sách hội thoại, trả lời dạng stream, nối backend riêng) thành ứng dụng đầy đủ. Với `--lang en`, chuỗi có sẵn của component cũng là tiếng Anh; `--lang vi` không tải thêm gì. Template dùng `yugen-ui` 0.11. [→](/templates)

## Cải tiến

- `yugen init` tự bọc app trong YugenProvider (`main.tsx` của Vite, `app/layout.tsx` của Next.js); `create --ref` lấy template từ một nhánh hoặc tag. [→](/concepts/cli)
- `create --lang en|vi` có thêm template SaaS và Blog; xoá luôn thư mục `src/content/<ngôn ngữ kia>/` (bài viết của blog), không chỉ file `.ts`. [→](/templates)
- `create --lang` ghi luôn tiêu đề, description và thẻ Open Graph của ngôn ngữ đó vào `index.html`, để bản xem trước khi chia sẻ link và công cụ tìm kiếm thấy đúng ngôn ngữ. [→](/templates)

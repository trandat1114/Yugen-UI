# First release

Create an app from a template, set up an existing project and copy component source, all with one command line tool.

## New

- `create`: creates an app from the `starter`, `saas`, `blog`, `dashboard` or `ai-chat` template. The templates ship inside the package, so no network is needed. [→](/concepts/cli)
- `init`: sets up an existing React project with the npm package or by copying source code, and saves the config to `yugen.json`. [→](/concepts/cli)
- `add` and `list`: copy components along with the components they depend on, install missing npm packages, and search the registry. [→](/concepts/cli)
- `doctor`: checks React, Tailwind CSS v4, the theme import, the `yugen-ui` version and YugenProvider. [→](/concepts/cli)

# Node.js 22, --lang and new templates

`create` can choose the starter's language, and Node.js 22 or later is required.

## Breaking

- Requires Node.js 22 or later (Node.js 20 has reached end of life). [→](/concepts/cli)

## New

- `create --lang en|vi` sets the language of the app's text for templates that have both (the starter). Without it, interactive runs ask; the default is English. [→](/concepts/cli)

## Improved

- Templates have short names in the picker. The starter is a minimal English page with its text in `src/content/`, and new apps use React 19. [→](/templates)

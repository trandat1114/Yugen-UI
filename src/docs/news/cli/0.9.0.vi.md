# Kiểm tra item registry bằng checksum đi kèm CLI

`add`, `update` và các lệnh registry khác đọc registry của đúng phiên bản `yugen-ui` mà template dùng, rồi so từng item với sha256 có sẵn trong CLI trước khi ghi file nào. Các template chuyển sang `yugen-ui` 0.17.

## Mới

- `add`, `init`, `update`, `diff`, `list` và `remove` đọc `<docs>/r/<phiên bản>/` theo phiên bản `yugen-ui` của template và so từng item với `dist/registry-integrity.json`. Sai lệch thì dừng trước khi ghi bất cứ thứ gì. Registry truyền qua `--registry` hoặc khai báo trong `yugen.json` / `components.json` không được kiểm tra, và CLI báo rõ điều đó. [→](/concepts/cli)

## Cải tiến

- `yugen css` và `init` thêm `yugen-ui/tokens/brands.css` khi app dùng brand web hoặc Teams, vì `theme-core.css` không còn chứa hai brand này. [→](/concepts/cli#css)
- Template dùng `yugen-ui` 0.17: `vite-admin` kiểm tra form bằng `HookForm` và `standardSchemaResolver` từ `yugen-ui/form`, `vite-dashboard` và `vite-saas` import component ngày tháng từ `yugen-ui/dates` kèm `react-day-picker`, `vite-store` tô card radio đang chọn bằng `has-checked:`. [→](/templates)

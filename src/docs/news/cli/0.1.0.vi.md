# Bản đầu tiên

Tạo app từ template, thiết lập dự án có sẵn và chép mã nguồn component bằng một công cụ dòng lệnh.

## Mới

- `create`: tạo app từ template `starter`, `saas`, `blog`, `dashboard` hoặc `ai-chat`. Template đóng gói sẵn nên không cần mạng. [→](/concepts/cli)
- `init`: thiết lập dự án React có sẵn bằng gói npm hoặc chép mã nguồn, ghi cấu hình vào `yugen.json`. [→](/concepts/cli)
- `add` và `list`: chép component kèm component phụ thuộc, cài gói npm còn thiếu, tìm trong registry. [→](/concepts/cli)
- `doctor`: kiểm tra React, Tailwind CSS v4, import theme, phiên bản `yugen-ui` và YugenProvider. [→](/concepts/cli)

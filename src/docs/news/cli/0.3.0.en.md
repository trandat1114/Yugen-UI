# Templates on Vite 8

New apps run on Vite 8 and TypeScript 6, and `doctor` no longer warns about a freshly created app.

## Improved

- Every template uses Vite 8 (Rolldown), `@vitejs/plugin-react` 6 and TypeScript 6. Chunks are split with `codeSplitting` instead of the deprecated `manualChunks`, and `tsconfig` no longer sets `baseUrl`. [→](/templates)

## Fixed

- `doctor`, `add`, `list`: a project that has `yugen-ui` installed but no `yugen.json` (an app made with `create`, or one set up by hand from the README) is treated as package mode. `doctor` stops warning, and `add` prints the import line instead of asking you to run `yugen init`. [→](/concepts/cli)

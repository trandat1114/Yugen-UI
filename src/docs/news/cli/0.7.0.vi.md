# Template dùng yugen-ui 0.15: trang lỗi, React 19 và TypeScript 7

Template ghim `yugen-ui@^0.15.0`, bản cần React 19. Trang bị lỗi hiện trang trạng thái thay vì màn hình trắng, và template Vite kiểm tra kiểu bằng TypeScript 7, trình biên dịch native.

## Thay đổi lớn

- Template và component thêm bằng `add` cần React 19 trở lên, như `yugen-ui` 0.15.0. `doctor` báo React 18 là lỗi. [→](/concepts/cli)

## Mới

- Template Vite bắt lỗi render bằng `ErrorBoundary`: trang bị lỗi hiện trang trạng thái có nút Thử lại, hoặc Tải lại khi một file không tải được sau lần deploy. `saas` và `starter` hiện trang 404 cho đường dẫn không tồn tại, `landing` tạo `404.html` tĩnh khi build. [→](/components/statuspage)

## Cải tiến

- Template Vite dùng TypeScript 7 (`^7.0.2`): `npm run build` kiểm tra kiểu nhanh hơn nhiều lần. `next-starter` vẫn dùng TypeScript 6, vì `next build` kiểm tra kiểu qua JavaScript API của TypeScript. Template ghim `yugen-ui@^0.15.0`. [→](/templates)

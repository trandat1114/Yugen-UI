# Template dùng Vite 8

App mới chạy Vite 8 và TypeScript 6; `doctor` không còn cảnh báo app vừa tạo.

## Cải tiến

- Mọi template dùng Vite 8 (Rolldown), `@vitejs/plugin-react` 6 và TypeScript 6; chia chunk bằng `codeSplitting` thay cho `manualChunks` đã deprecated, `tsconfig` không còn `baseUrl`. [→](/templates)

## Sửa lỗi

- `doctor`, `add`, `list`: dự án đã cài `yugen-ui` mà chưa có `yugen.json` (app tạo bằng `create`, hoặc cài tay theo README) được hiểu là mode package; `doctor` hết cảnh báo, `add` in sẵn dòng import thay vì đòi chạy `yugen init`. [→](/concepts/cli)

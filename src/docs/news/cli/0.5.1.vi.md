# Template Glass: mùa hoa anh đào ở Nhật Bản

Template Glass có thêm bốn chuyến đi ở Nhật Bản, khúc xạ ở mép glass, khung xem trước trên ảnh trong trang Cài đặt và bản đồ thế giới ở trang Khám phá. Template Blog và Docs định dạng bài viết bằng Prose.

## Cải tiến

- `npx create-yugen-ui@latest my-app --template glass`: chuyến đi ở Kyoto, Tokyo, Hirosaki và quanh núi Phú Sĩ, GlassRefraction ở gốc app, trang Cài đặt xem trước trên ảnh sáng, ảnh hoa và ảnh đêm, trang Khám phá là bản đồ thế giới với ghim theo toạ độ thật. Template ghim `yugen-ui@^0.13.0`. [→](/templates)
- Template blog và docs: bài viết Markdown định dạng bằng Prose của `yugen-ui` thay cho class riêng trên từng thẻ. [→](/components/prose)

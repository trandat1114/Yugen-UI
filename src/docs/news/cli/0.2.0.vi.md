# Node.js 22, --lang và template mới

`create` chọn được ngôn ngữ cho starter; cần Node.js 22 trở lên.

## Thay đổi lớn

- Cần Node.js 22 trở lên (Node.js 20 đã hết hỗ trợ). [→](/concepts/cli)

## Mới

- `create --lang en|vi` chọn ngôn ngữ chữ trong app với template có cả hai (starter). Không truyền thì hỏi khi chạy tương tác; mặc định tiếng Anh. [→](/concepts/cli)

## Cải tiến

- Template có tên ngắn trong trình chọn; starter tối giản bằng tiếng Anh, chữ nằm trong `src/content/`; app mới dùng React 19. [→](/templates)

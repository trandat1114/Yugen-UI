# Template Glass, Landing, Admin và Next.js

Thêm template Glass (nhật ký du lịch với điều hướng glass), Landing (trang giới thiệu sản phẩm), Admin (trang quản trị khách hàng và đơn hàng) và Next.js starter (App Router).

## Mới

- `create --template landing`: trang giới thiệu sản phẩm với bảng giá, hỏi đáp và form đăng ký; màn hình đầu và thẻ SEO sinh sẵn lúc build; tiếng Anh hoặc tiếng Việt (`--lang vi`). [→](/templates)
- `create --template admin`: trang quản trị với DataGrid phân trang trên server, form trong Drawer có kiểm tra, cập nhật lạc quan và đăng nhập có mã OTP; tiếng Anh hoặc tiếng Việt (`--lang vi`). [→](/templates)
- `create --template next-starter`: dự án Next.js App Router, theme lưu trong cookie để server render đúng theme ngay từ HTML đầu tiên; có tiếng Việt với `--lang vi`. [→](/concepts/ssr)
- `create --template glass`: nhật ký du lịch với sidebar, thanh tab, toolbar và bottom sheet bằng glass nổi trên ảnh; tiếng Anh hoặc tiếng Việt (`--lang vi`). [→](/templates)
- `create --template docs`: trang tài liệu từ Markdown với sidebar theo thư mục, tìm kiếm Ctrl K và HTML sinh sẵn cho từng trang; tiếng Anh hoặc tiếng Việt (`--lang vi`). [→](/templates)
- `create --template store`: cửa hàng nhỏ với bộ lọc trong URL, giỏ hàng trong Sheet và thanh toán nhiều bước có kiểm tra; giá theo USD hoặc VND tuỳ ngôn ngữ (`--lang vi`). [→](/templates)

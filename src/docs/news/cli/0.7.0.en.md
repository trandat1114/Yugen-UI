# Templates on yugen-ui 0.15: error pages, React 19 and TypeScript 7

The templates pin `yugen-ui@^0.15.0`, which needs React 19. A page that fails shows a status page instead of a blank screen, and the Vite templates type-check with TypeScript 7, the native compiler.

## Breaking

- Templates and the components added with `add` need React 19 or later, like `yugen-ui` 0.15.0. `doctor` reports React 18 as an error. [→](/concepts/cli)

## New

- Vite templates catch render errors with `ErrorBoundary`: a page that fails shows a status page with Try again, or Reload when a file failed to load after a deploy. `saas` and `starter` show a 404 page for unknown paths, and `landing` writes a static `404.html` at build time. [→](/components/statuspage)

## Improved

- Vite templates use TypeScript 7 (`^7.0.2`): `npm run build` type-checks several times faster. `next-starter` stays on TypeScript 6, because `next build` type-checks through TypeScript's JavaScript API. The templates pin `yugen-ui@^0.15.0`. [→](/templates)

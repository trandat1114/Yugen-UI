# Glass, Landing, Admin and Next.js templates

New templates: Glass (a travel journal with glass navigation), Landing (a product landing page), Admin (customer and order management) and a Next.js starter (App Router).

## New

- `create --template landing`: a product landing page with pricing, an FAQ and a sign-up form. The first screen and the SEO tags are generated at build time. English or Vietnamese (`--lang vi`). [→](/templates)
- `create --template admin`: an admin app with a server-paginated DataGrid, validated forms in a Drawer, optimistic updates and sign-in with a one-time code. English or Vietnamese (`--lang vi`). [→](/templates)
- `create --template next-starter`: a Next.js App Router project. The theme is stored in a cookie, so the server renders the right theme in the very first HTML. Vietnamese is available with `--lang vi`. [→](/concepts/ssr)
- `create --template glass`: a travel journal with a glass sidebar, tab bar, toolbar and bottom sheet floating over photos. English or Vietnamese (`--lang vi`). [→](/templates)
- `create --template docs`: a documentation site built from Markdown, with a sidebar based on folders, Ctrl K search and prebuilt HTML for every page. English or Vietnamese (`--lang vi`). [→](/templates)
- `create --template store`: a small shop with filters in the URL, a cart in a Sheet and a validated multi-step checkout. Prices in USD or VND, depending on the language (`--lang vi`). [→](/templates)

# Templates built on AppShell, a Kanban board in the Admin template

Nine templates are built on the AppShell of `yugen-ui` 0.14.0 instead of their own frame. The Admin template adds a Board page where tasks move between columns by drag and drop. The CLI now needs Node.js 24 or newer.

## Breaking

- Requires Node.js 24 or newer: Yugen UI supports the two newest Node.js LTS lines (24 and 26 today). [→](/concepts/cli)

## New

- Template admin: a Board page (Kanban) built with Sortable, with mouse, touch or keyboard. The order is saved on drop; when the request fails, the task goes back and a toast says so. [→](/components/sortable)

## Improved

- Templates starter, saas, blog, dashboard, ai-chat, admin, docs, store and landing: the sidebar collapses to icons or opens as a Drawer on narrow screens, Ctrl+B / ⌘B toggles it, and a skip link goes to the main content. The templates pin `yugen-ui@^0.14.0`. [→](/templates)

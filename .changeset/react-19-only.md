**Breaking:** React 19 or later is required (`peerDependencies` `react` / `react-dom` `>=19`). React 18.3 was supported through 0.14; it gets no fixes upstream since 2024-04, and CI no longer tests it. Apps on React 18 can stay on `yugen-ui@0.14` until they upgrade (#62).

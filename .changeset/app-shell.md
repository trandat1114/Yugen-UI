New `AppShell` (#161): the frame of an app, with `AppShellHeader`, `AppShellMain`, `AppShellAside` and a `Sidebar` (`SidebarHeader`, `SidebarContent`, `SidebarFooter`, `SidebarGroup`, `SidebarTrigger`, `SidebarRail`). From `breakpoint` up (a container query) the sidebar sits in the layout and collapses to an icon rail (`collapsible="icon"`, Nav labels move to Tooltips) or hides (`"offcanvas"`); below it the same content opens in a Drawer that closes when a link is followed or a Nav item is chosen. `Sidebar resizable` turns `SidebarRail` into a keyboard-operable splitter. Ctrl+B / ⌘B toggles the sidebar (`shortcut`), except in text fields, contenteditable and during IME composition. `persistKey` keeps the collapsed state and width in a cookie (read it on the server with `readAppShellCookie`); the Drawer is never saved. When the frame crosses the breakpoint with the Drawer open, it closes and focus returns to the trigger, or to the main region if the trigger is hidden. Skip link to the main region, `useAppShell()` for custom parts, strings in `messages.appShell`. `NavItem` gains `tooltip`. The SaaS, Dashboard and AI chat templates use it.

Prose reads its fonts and rhythm from CSS variables: `--prose-font-body`, `--prose-font-heading`, `--prose-font-mono`, `--prose-size`, `--prose-leading` and `--prose-flow` (space between blocks). With none of them set it looks exactly as before. New presets in the theme: `yugen-prose-docs`, `yugen-prose-article`, `yugen-prose-chat` and `yugen-prose-compact`. The docs have a Typeset page that builds your own preset and copies the CSS (#244).
